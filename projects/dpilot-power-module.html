DPilot and Power Module

DPilot

A modular, custom-designed control platform for UAV, UGV, and USV applications, developed with a focus on reliability, scalability, and autonomous operation.

Key Features

  • Fail-operational architecture with modular BaseBoard and ExpansionBoard
  • Custom PCB design and embedded firmware development
  • Redundant sensor configuration with dual IMUs, barometers, and magnetometer
  • Dual-band RF communication and onboard data logging
  • Integrated power management and system monitoring
  • Hardware support for autonomous and manual control
  • Companion computer integration for AI-based navigation and computer vision

Power Module

A custom-designed power distribution and monitoring module developed to enhance the reliability and safety of autonomous robotic platforms.

Key Features

  • Redundant power architecture designed to eliminate single points of failure
  • Independent power paths for propulsion and control systems
  • Redundant power inputs and outputs
  • Dedicated high-current output for servos
  • Real-time voltage, current, and temperature monitoring
  • Integrated system health monitoring and fault detection
  • Embedded communication with the DPilot controller for power diagnostics and system status reporting
