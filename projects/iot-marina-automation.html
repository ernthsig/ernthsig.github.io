IoT Marina Automation

A custom-designed IoT sensor and computer vision system developed to automate marina berth occupancy detection and management through real-time monitoring.

Key Features

  • Custom hardware design and manufacturing of ultrasonic occupancy sensors
  • LoRa wireless communication for long-range data transmission
  • Custom Raspberry Pi-based LoRa gateway with MQTT backend integration
  • Python-based computer vision using OpenCV and NumPy for berth occupancy detection
  • Automated occupancy data reporting to backend systems via MQTT and JSON
  • Integration of IoT sensor data and image processing for marina management
